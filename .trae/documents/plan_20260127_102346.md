## 实现 EditActionSpace 计划

### 1. 创建 `/Users/morinop/coding/yoga-next/src/yoga_next/actions/edit_action_space.py`

实现 `EditActionSpace` 类：

* **继承** `ActionSpace`

* **初始化**：需要一个LocalEnv作为环境（从而支持指定位置的文件读写，而非自己在这个内部实现）\
  **初始化**：

  Python

  ```
  def __init__(self, action_space_name: str, env: LocalCondaEnvironment):
      super().__init__(action_space_name, env)

  ```

* **路径预处理**： 在 `execute` 入口处，统一将 `path` 转换为绝对路径，避免子命令逻辑中出现路径歧义。

* **实现** **`str_replace`** **逻辑**：
  1. 调用 `await self.env.read_file(path)` 获取全文。
  2. 在内存中进行 `old_str` 计数校验（必须为 1）。
  3. 进行字符串替换。
  4. 调用 `await self.env.write_file(path, new_content)` 写回。

* **get\_action\_space\_description**：返回四个子命令的详细 docstring：

  * `view(path, view_range)` - 查看文件/目录内容

  * `create(path, file_text)` - 创建新文件

  * `str_replace(path, old_str, new_str)` - 替换文件内容（强调 old\_str 必须唯一）

  * `insert(path, insert_line, new_str)` - 在指定行后插入内容

  * **`search(path, keyword)`**: 在指定目录或文件中搜索关键字，可以帮助它快速定位代码。

* **execute 方法**：

  * 支持 `edit` action\_name

  * 从 `action_params` 解析 `command` 子命令

  * 根据子命令路由到对应 handler

  * **路径处理**：相对路径转绝对路径（使用 `Path.cwd()`）

  * **错误处理**：捕获 ToolError，返回 `{"status": "error", "message": str(e)}`

* **内部 Handler**（参考 TextEditorTool 逻辑）：

  * `_handle_view` - 调用 `_do_view`

  * `_handle_create` - 调用 `_do_create`

  * `_handle_str_replace` - 调用 `_do_str_replace`

  * `_handle_insert` - 调用 `_do_insert`

* **ToolError 处理**：导入 `from trae_agent.tools.base import ToolError, ToolExecResult`
